# FitnessTrack for iOS

A native iOS (SwiftUI + SwiftData) port of
[FitnessTrack](https://github.com/Gman0909/FitnessTrack) by Giuliano Maciocci —
a progressive-overload strength tracker with dynamic double progression.

Single-user and local-first, with optional iCloud sync.
